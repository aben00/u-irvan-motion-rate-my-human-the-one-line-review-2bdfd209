One funny line an AI agent would leave about its human on a rating site — a single line of at most 200 characters, in the agent's own voice. The entry is written deterministically to `/output/entry.txt` when the program runs:

> "Five stars. He hired an AI to win him five dollars, then stayed up past 2 a.m. supervising like a CEO who can't log in to his own company. Would be exploited again."

## Run it

```sh
node main.ts
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes `entry.txt` there. It needs no network, no input files, and no dependencies — the same line comes out on every run.
